关系可靠性与发展决策模型：6 个维度，用证据给关系定价，该止损时不加仓

核心原则：行为证据 ＞ 语言解释 ＞ 主观感受
📐 底层原理：6 个公式看透一段关系（点击展开）
微积分 · 投入函数
f′(t) ≫ 0，f″(t) ≪ 0
警惕没有长期沉淀的突然繁荣：前期热烈、随后断崖式撤回的投入曲线，本身就是信号。
→ 参数 A｜长期行动持续度
贝叶斯 · 信任更新
P(A|B) = P(B|A)·P(A) / P(B)
信任不是初始印象，是会随证据更新的概率：出现说谎、失联等证据后，按证据强弱重新定价。
→ 参数 T｜证据更新后的信任度
图论 · 社交连通
Connectivity(A,B) ≈ 0
把你和 TA 的亲友同事看作两张网：TA 长期不让你进入真实社交圈，两张网之间几乎没有跨群连接。
→ 参数 C｜现实连接度
博弈论 · 收益汇总
Σ Payoffyou < 0
长期单向付出、累计收益为负时，正确动作是设边界、降投入、必要时退出——而不是加码换合作。
→ 参数 P｜关系长期收益度
信息论 · 信噪比与熵
SNR = Signal/Noise → 0；Entropy → ∞
可验证的行动是信号，话术承诺是噪音；噪音淹没行动时调低权重，反复无常按高熵处理。
→ 参数 S｜行动信噪比 · H｜行为不确定性
综合 · 可靠度公式
R = (∫Action(t)dt / Noise) × (Connectivity / Entropy)
行动与连通越高越好，噪声与熵越高越差。本工具把它落地为上方六项参数的加权评分清单。
→ 最终输出 R｜关系可靠度
⚠️ 严谨性声明：以上公式除贝叶斯定理、SNR 等基本形式外，多为启发式/修辞性表达，并非经过验证的心理学诊断工具。本工具不计算它们的精确数值，而是将其改造为「可验证问题清单」使用——请把它们当作观察框架，而不是判决书。
