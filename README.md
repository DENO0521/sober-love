# 关系可靠性与发展决策模型

「行为证据 > 语言解释 > 主观感受。」

License: MIT

一个纯前端的交互式评估工具：输入 6 个客观参数，自动计算关系可靠度 R 值，完成结构性风险检查，并给出下一阶段的具体行动方案。
不是心理测试，不是情感鸡汤——是一个把「证据」和「感觉」强制分开的决策工具。

## 核心模型

六项参数（0–100）：

| 参数 | 含义 | 权重 |
|------|------|------|
| A｜长期行动持续度 | 说过的事情是否长期真的做到 | 0.25 |
| T｜证据更新后的信任度 | 已有证据支持相信 TA 的程度 | 0.25 |
| C｜现实连接度 | 是否逐渐进入 TA 的真实生活 | 0.15 |
| P｜关系长期收益度 | 关系是否总体互惠 | 0.15 |
| S｜行动信噪比 | 可信信息来自行动还是语言 | 0.10 |
| H｜行为不确定性 | 行为是否反复混乱（越高越危险） | 0.10（反向） |

```
R = 0.25A + 0.25T + 0.15C + 0.15P + 0.10S + 0.10(100−H)
```

但总分从来不是结论。模型强制进行**结构性风险检查**：

- T < 40 → 诚信高风险；A < 40 → 行动可靠性高风险
- T 与 A 双低 → 即使 R > 50 也不可快速发展
- C < 40 现实隔离 / P < 40 关系失衡 / S < 40 语言噪音 / H > 60 高不确定性
- 硬性红旗（已确认的重大欺骗、隐瞒伴侣、金钱欺骗、操控、威胁暴力等）拥有最高优先级，不允许被平均分稀释

## 功能清单

- 📊 **实时计算**：R 值 + 完整计算过程 + 五档风险等级
- 🎯 **一句话结论**：五档明确结论，拒绝模棱两可
- 🧱 **结构性风险检查**：核心变量单独亮红牌，不被总分掩盖
- 🧭 **人品/诚信四维判断**：诚信 / 责任感 / 一致性 / 互惠性各评高中低
- ⚠️ **三大危险指标排序**：只解释为什么重要，不替对方找理由
- 🔍 **假性高分检测**：手动线索 + 参数矛盾自动检测（如 P 高但 C 低）
- 📋 **ABCD 四选一行动方案**：继续发展 / 减速发展 / 观察期 / 停止发展
- ✅ **下一阶段验证任务**：最多 3 条，全部基于正常真实互动（不试探、不钓鱼、不查手机）
- 🔄 **结论修正清单**：什么证据提高判断、什么证据降低判断、什么情况必须重新评估

## 打分体系（三层锚定）

打分最大的敌人是自己的主观偏差。工具用三层结构对抗它：

1. **档位锚点**：每档配具体行为描述（如 T 的 70–89 =「总体可信，有少量解释不清的问题」），打分必须对号入座
2. **证据参考值**：每项 5 个可验证的是/否证据问题，每题 20 分，生成「证据底线」参考值
3. **偏差警报**：输入值偏离证据参考值 ±15 分即亮红牌；结果区同时显示「输入版 R」与「证据版 R」，整体漂移 ≥5 分时发出乐观/悲观警告

工具不能消除偏差，但能让偏差显性化。
